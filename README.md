# 可可手作 · 宋锦饰品商城 H5 高保真原型

> **品牌**：可可手作 · 一寸宋锦 一寸心意
> **形态**：H5 网页商城（移动端优先 + PC 后台）
> **技术栈**：Vue 3 + Vite + Vant 4 + Vue Router + Pinia
> **状态**：高保真原型（Mock 数据，可点击交互，可作设计参考）

## 设计调性

- **主色**：朱砂红 `#7A2E2A`（点缀 + 头部 / 按钮）
- **中性色**：黛黑 `#2B2118`（主文字）/ 米杏 `#F5EFE6`（背景）
- **点缀色**：金箔 `#C9A961`（高端感）
- **字体**：标题用思源宋体（衬线，宋锦调性），正文用苹方/微软雅黑
- **风格**：新中式典雅，留白克制，徽章/装饰用金线点缀
- **圆角**：偏圆润（8~20px），避免尖锐

## 后续转生产

这套原型可以直接作为前端基础，转成可上线版本需要补：

1. **后端 API**（Node.js Express / 选 Java Spring Boot / PHP 都可以）
2. **数据库**（MySQL 8）— schema 参考 `mock.js` 结构
3. **微信支付**（H5 JSAPI，需要商户号 + 业务域名配置）
4. **微信开放平台**（微信登录 + JSSDK）
5. **部署**（域名 + 备案 + 阿里云/腾讯云轻量服务器）
6. **测试**（主要测试支付回调、拼团成团、接龙截单逻辑）
